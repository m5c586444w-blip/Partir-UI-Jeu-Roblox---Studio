# Polices de mesure (outil seulement)

Utilisées par `tools/ui/check_ui.py` pour mesurer les textes et dessiner les aperçus de `previews/`.
Ce ne sont pas des assets du jeu : dans Roblox, les polices viennent de l'enum `Font` (15.2).

| Fichier | Police | Auteur | Licence | Source |
| --- | --- | --- | --- | --- |
| `SpecialElite.ttf` | Special Elite | Astigmatic | Apache License 2.0 | https://github.com/google/fonts/tree/main/apache/specialelite |
| `RobotoMono.ttf` | Roboto Mono (variable) | Christian Robertson | SIL Open Font License 1.1 | https://github.com/google/fonts/tree/main/ofl/robotomono |
